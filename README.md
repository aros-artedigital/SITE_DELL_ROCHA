## 📌 Sobre o Projeto

O portal foi desenvolvido com o objetivo de apresentar o acervo musical e a trajetória de Dell Rocha para cantores, bandas, produtores e apreciadores da música popular brasileira.

Através de uma interface dinâmica e responsiva, o visitante pode navegar pelas composições, escutar prévias em áudio, conhecer faixas gravadas por grandes artistas e entrar em contato direto para negociação de composições inéditas.

---

## ✨ Funcionalidades Principais

- 🚀 **Slider de Destaques:** Apresentação de lançamentos recentes, músicas em alta e chamadas para artistas/produtores.
- 🎧 **Player de Áudio Integrado:** Reprodução direta de faixas e prévias musicais via HTML5 Audio.
- 🎶 **Categorização de Músicas:**
  - **Mais Ouvidas:** As obras de maior destaque do catálogo.
  - **Estouradas:** Ranking de músicas com maior repercussão no público.
  - **Lançamentos:** Novas criações recém-saídas do estúdio.
  - **Gravadas por Artistas:** Músicas do compositor interpretadas por outros cantores.
- 🎷 **Navegação por Ritmos:** Filtros rápidos por gêneros como *Arrocha, Seresta, Forró, Piseiro, Brega e Sofrência*.
- 📲 **Integração Comercial via WhatsApp:** Links diretos para contato com o compositor e solicitação de composições sob encomenda.
- ♿ **Acessibilidade e Usabilidade:** Estrutura semântica com suporte a leitores de tela (`aria-*`, navegação via teclado e salto direto para conteúdo principal).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica e acessível.
- **CSS3:** Estilização moderna, responsividade e animações sutis.
- **JavaScript (ES6+):** Lógica do player de áudio, navegação interativa e sliders.
- **Google Fonts:** Tipografia personalizada para o projeto.
- **Netlify:** Hospedagem e deploy contínuo.

## 💻 Como Executar o Projeto Localmente

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/dellrocha-website.git
   ```

2. **Acessar o diretório:**
   ```bash
   cd dellrocha-website
   ```

3. **Abrir no navegador:**
   - Basta abrir o arquivo `index.html` em qualquer navegador web, ou utilizar uma extensão como o [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code.
